參考資料

沒有多埠封包分析儀怎麼辦

① 流量回環打流法

伺服器（Linux + TRex）配雙埠 1G 與雙埠 10G 網卡，兩路同時打流：A 路從 1G 網卡進 P1，經 3 條跳線串成菊花鏈，從 P8 回到伺服器；B 路從 10G 網卡進 SFP+1，路由轉發到 SFP+2 再回到伺服器。

A：1G-a → P1 → P2–P3 → P4–P5 → P6–P7 → P8 → 1G-b
B：10G-1 → SFP+1 → SFP+2 → 10G-2

菊花鏈中間都是 1G，不能從 SFP+ 送 10G 進去：超過 1G 會掉包，10G 埠也測不到線速。

② PoE 實體抽載

每埠接一組 PoE Splitter，再把電阻或電子負載接在 Splitter 的 DC 輸出端，8 組同時抽電。單接電阻無法通過 PoE 偵測，交換器不會送電。

RFC 2544 / 2889 重點

網路設備基準測試方法

RFC 2544

Throughput（零掉包下最大速率）、Latency、Frame Loss Rate、Back-to-Back（可承受的連續突發長度）。標準封包：64 / 128 / 256 / 512 / 1024 / 1280 / 1518 B。

LAN 交換設備基準測試

RFC 2889

Fully Meshed（全部埠互打）、Congestion Control（壅塞與隊頭阻塞）、Address Caching / Learning（MAC 表容量與學習速率）、Broadcast（廣播轉發與延遲）。

本案應用：RFC 2544 驗證 41.666 Mpps 零掉包；RFC 2889 驗證多埠同時打流與 MAC 學習；10240B Jumbo 為額外加測，不在 RFC 2544 標準尺寸內。

常見問題 補充

為什麼規格書的轉發能力剛好是 41.666 Mpps？

它就是 64B 線速：1G 埠 1.488 Mpps × 8 ＋ 10G 埠 14.88 Mpps × 2 ≈ 41.666 Mpps。交換容量 56 Gbps 則是 (8×1G + 2×10G) × 2（全雙工，收與送各算一次）。

IMIX 是什麼？

Internet Mix，混合不同大小封包的測試流量，模擬真實網路。最常見的 Simple IMIX 是 64B : 594B : 1518B = 7 : 4 : 1（依個數），平均約 362B，1G 埠線速約 327 kpps。

IMIX 沒有唯一標準，Spirent、IXIA 各有版本，RFC 6985 規範了標示方式。測試計畫與報告要寫清楚用哪一種。

為什麼 44V 比 54V 嚴苛？

功率 P = V × I。輸入功率相同時，電壓越低電流越大，內部 DC-DC 轉換與導線的發熱（I²R）也越高。上方的功耗計算器可以直接看到差異。

每埠 30W 和 25.5W 差在哪？

30W 是交換器（PSE）每埠的輸出上限，25.5W 是受電設備（PD）端保證收到的功率，差額是 100m 網路線的損耗上限。測試時要確認負載儀的設定是哪一端。

72 小時是怎麼決定的？

來自本測試規劃的 Burn-in 要求，用來觀察長時間運轉下的熱平衡、記憶體洩漏與偶發錯誤。實際時數可依產品驗證規範或客戶要求調整。

沒有 Spirent / IXIA 能做嗎？

可以先用附錄的替代方案：TRex 搭配 A＋B 兩路回環打流，PoE 用 Splitter 加負載（接線圖與動畫）。但量測精度與 RFC 報告的完整度會受限，正式驗證仍建議使用專用儀器。
